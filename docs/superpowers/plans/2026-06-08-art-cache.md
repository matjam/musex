# Art Caching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** Cache all artwork (album/artist/track thumbs, etc.) to disk so it's served locally on repeat and **across restarts** — instead of re-fetching from Plex every launch.

**Why our own cache (not the browser's):** art is served through the stream proxy, whose URL embeds the **per-launch random port + secret**, so the URL changes every launch and Chromium's HTTP cache can't reuse anything across restarts. A main-side disk cache keyed by the **stable Plex path** fixes that. We **reuse the existing `MediaCache`** class (generic write-through, LRU, disk file cache) pointed at a new `art-cache/` dir.

**Decisions (confirmed):** art cache is **always-on** (independent of the audio "Local Cache" toggle; small files, universal win), own ~1 GB LRU cap. Settings shows **combined** (audio + art) size with **one Clear** that wipes both.

**Architecture:** unchanged boundaries — a second `MediaCache` instance in `Runtime` (`art-cache/`), used by the `StreamProxy` for art paths regardless of the audio cache config. Disk-serve sets the right image `Content-Type` by sniffing magic bytes (art URLs have no file extension), plus `Cache-Control: immutable` so the browser also caches within a session.

**Conventions:** main/logic `.js` imports; test/renderer no extension; `import type`; Biome; `noUncheckedIndexedAccess`. `git add -A`; commit to `main`; push each commit. Each task ends GREEN on `pnpm check`.

```ts
/** Plex artwork/image paths (album/artist/track thumbs, background art, resized photos). */
export function isArtPath(plexPath: string): boolean {
  return (
    plexPath.includes("/thumb/") || plexPath.includes("/art/") || plexPath.startsWith("/photo/")
  );
}

/** Best-effort image MIME from a file's leading bytes (art URLs carry no extension). */
export function sniffImageType(head: Uint8Array): string {
  if (head[0] === 0xff && head[1] === 0xd8 && head[2] === 0xff) return "image/jpeg";
  if (head[0] === 0x89 && head[1] === 0x50 && head[2] === 0x4e && head[3] === 0x47) return "image/png";
  if (head[0] === 0x47 && head[1] === 0x49 && head[2] === 0x46 && head[3] === 0x38) return "image/gif";
  if (
    head[0] === 0x52 && head[1] === 0x49 && head[2] === 0x46 && head[3] === 0x46 &&
    head[8] === 0x57 && head[9] === 0x45 && head[10] === 0x42 && head[11] === 0x50
  ) {
    return "image/webp";
  }
  return "application/octet-stream";
}
```

```ts
  private async readHead(filePath: string, n: number): Promise<Uint8Array> {
    const fh = await open(filePath);
    try {
      const buf = Buffer.alloc(n);
      const { bytesRead } = await fh.read(buf, 0, n, 0);
      return buf.subarray(0, bytesRead);
    } finally {
      await fh.close();
    }
  }
```
