# Queue Prefetch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** While a track plays, proactively download the next **10** queued direct-play tracks into the on-disk media cache (in the background, in main), so upcoming tracks play instantly / offline. Active only when "Local Cache" is enabled; HLS/transcoded tracks skipped; stale prefetches cancel when the queue changes; bounded concurrency.

**Architecture:** A `prefetch` capability on the main-process `StreamProxy` (it already holds the per-server endpoints, the media cache, the cache config, and the cache-write pattern). It fetches each upcoming track from Plex straight into `MediaCache` (no client response, no renderer byte-transfer), reusing the decoupled best-effort write. The renderer triggers it from the player store whenever the upcoming set changes. No core changes.

**Tech Stack:** Electron main (Node http/https), React 19 renderer, TS 6, Biome 2.

**Conventions:** main/shared `.js` imports; renderer no extension; `import type`; Biome; `noUncheckedIndexedAccess`; lucide-only (n/a here). `git add -A`; commit to `main`; push each commit; each task ends GREEN on `pnpm check`.

**Constants:** `PREFETCH_DEPTH = 10`, `PREFETCH_CONCURRENCY = 2`.

### Task 1: Main — `StreamProxy.prefetch` + cache-from-upstream helper

**Files:** `packages/desktop/src/main/adapters/stream-proxy.ts`

Reuse the proxy's existing fields (`endpoints`, `cache`, `readCacheConfig`) + helpers (`isCacheablePath`, `cacheKey`). Add a cache-only upstream fetch + a reconciling prefetch manager.

- [ ] **Step 1 (cache-from-upstream helper):** a private method that fetches one track from Plex directly into the media cache (no client; same decoupled best-effort write as the serve path), returning a cancel handle:
```ts
  private cacheFromUpstream(
    serverId: string,
    plexPath: string,
    key: string,
    maxBytes: number,
    onDone: () => void,
  ): () => void {
    const endpoint = this.endpoints.get(serverId);
    if (!endpoint || !this.cache) {
      onDone();
      return () => {};
    }
    const upstream = new URL(endpoint.baseUrl);
    upstream.pathname = plexPath;
    upstream.searchParams.set("X-Plex-Token", endpoint.token);
    const client = upstream.protocol === "https:" ? https : http;
    const writer = this.cache.beginWrite(key, maxBytes);
    let open = true;
    let finished = false;
    const finalize = (commit: boolean) => {
      if (open) {
        open = false;
        (commit ? writer.commit() : writer.abort()).catch((e) =>
          console.error("[musex prefetch] finalize error:", e),
        );
      }
      if (!finished) {
        finished = true;
        onDone();
      }
    };
    const req = client.request(upstream, { method: "GET" }, (res) => {
      if (res.statusCode !== 200) {
        res.resume(); // drain
        finalize(false);
        return;
      }
      const expected = Number(res.headers["content-length"] ?? "");
      let written = 0;
      res.on("data", (chunk: Buffer) => {
        written += chunk.length;
        if (open && !writer.stream.destroyed) writer.stream.write(chunk);
      });
      res.on("end", () => {
        const lengthOk = !Number.isFinite(expected) || expected <= 0 || written === expected;
        finalize(res.complete && lengthOk);
      });
      res.on("error", () => finalize(false));
    });
    req.on("error", () => finalize(false));
    req.end();
    return () => {
      req.destroy();
      finalize(false);
    };
  }
```

- [ ] **Step 2 (prefetch manager):** add an in-flight map + the reconciling entry point:
```ts
  private readonly prefetchInflight = new Map<string, () => void>(); // key -> cancel

  /** Warm the on-disk cache for the upcoming direct-play tracks (cacheable paths).
   *  Cancels in-flight prefetches no longer wanted; starts up to the concurrency
   *  limit; skips already-cached / in-flight. No-op when caching is disabled. */
  prefetch(upcoming: { serverId: string; plexPath: string }[]): void {
    const cfg = this.readCacheConfig?.();
    if (!cfg?.enabled || !this.cache) {
      this.cancelAllPrefetch();
      return;
    }
    const wanted = upcoming
      .filter((u) => isCacheablePath(u.plexPath))
      .slice(0, PREFETCH_DEPTH)
      .map((u) => ({ ...u, key: cacheKey(u.serverId, u.plexPath) }));
    const wantedKeys = new Set(wanted.map((w) => w.key));
    // Cancel in-flight prefetches that are no longer wanted.
    for (const [k, cancel] of this.prefetchInflight) {
      if (!wantedKeys.has(k)) {
        cancel();
        this.prefetchInflight.delete(k);
      }
    }
    void this.pumpPrefetch(wanted, cfg.maxBytes);
  }

  private async pumpPrefetch(
    wanted: { serverId: string; plexPath: string; key: string }[],
    maxBytes: number,
  ): Promise<void> {
    for (const w of wanted) {
      if (this.prefetchInflight.size >= PREFETCH_CONCURRENCY) return;
      if (this.prefetchInflight.has(w.key)) continue;
      if (!this.cache) return;
      if (await this.cache.pathIfPresent(w.key)) continue; // already cached
      // Re-check capacity after the await (it may have filled).
      if (this.prefetchInflight.size >= PREFETCH_CONCURRENCY || this.prefetchInflight.has(w.key)) {
        continue;
      }
      const cancel = this.cacheFromUpstream(w.serverId, w.plexPath, w.key, maxBytes, () => {
        this.prefetchInflight.delete(w.key);
        void this.pumpPrefetch(wanted, maxBytes); // start the next one
      });
      this.prefetchInflight.set(w.key, cancel);
    }
  }

  private cancelAllPrefetch(): void {
    for (const cancel of this.prefetchInflight.values()) cancel();
    this.prefetchInflight.clear();
  }
```
Add the constants near the top of the file: `const PREFETCH_DEPTH = 10;` and `const PREFETCH_CONCURRENCY = 2;`.

- [ ] **Step 3:** `pnpm check` green; `biome check` clean. Commit `feat(prefetch): StreamProxy.prefetch warms upcoming tracks into the cache` + push.

> Note: a prefetched track and the engine's gapless preload of the immediate-next track may briefly both fetch the same file; both write-throughs target the same cache key (atomic rename, last wins) — harmless. The `pathIfPresent` skip prevents prefetch from re-fetching once cached.

- [ ] **Step 2 (handler):** in `main/ipc.ts`, map each track to a direct-play cacheable path and hand to the proxy. Use `chooseStreamKind` (from `../logic/stream-kind.js`) to keep only direct tracks; ensure the proxy endpoint is registered for each server:
```ts
  ipcMain.handle(IPC.prefetch, async (_e, tracks: Track[]) => {
    const upcoming: { serverId: string; plexPath: string }[] = [];
    for (const t of tracks) {
      if (chooseStreamKind(t.media.audioCodec) !== "direct") continue;
      await rt.ensureProxyEndpoint(t.serverId);
      upcoming.push({ serverId: t.serverId, plexPath: t.media.partKey });
    }
    rt.proxy.prefetch(upcoming);
  });
```
(If `tracks` is empty or none are direct, `rt.proxy.prefetch([])` correctly cancels any stale in-flight prefetches.)

- [ ] **Step 3 (renderer trigger):** in `state/player.tsx` (`PlayerProvider`), trigger prefetch whenever the *upcoming set* changes — NOT on every position tick. Derive a stable key from the next `PREFETCH_DEPTH` track ids and effect on it:
```ts
  const PREFETCH_DEPTH = 10;
  const upcoming =
    state.queue != null
      ? state.queue.tracks.slice(state.queue.index + 1, state.queue.index + 1 + PREFETCH_DEPTH)
      : [];
  const upcomingKey = upcoming.map((t) => t.id).join(",");
  useEffect(() => {
    void window.musex.prefetch(upcoming);
    // upcomingKey captures the meaningful change; upcoming is derived from it.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [upcomingKey]);
```
Use the project's lint-ignore form Biome expects (a `// biome-ignore lint/correctness/useExhaustiveDependencies: keyed on upcomingKey` comment) rather than eslint syntax. Position updates re-render but `upcomingKey` is unchanged → no redundant prefetch calls. When the queue clears (`upcoming` empty), it sends `[]` → cancels stale prefetches.

## Self-Review

- **Coverage:** next-10 prefetch into the media cache (T1), gated on `cacheEnabled`, direct-only, dedup (pathIfPresent + in-flight), concurrency-limited (2), cancel-stale on queue change (T1 reconcile + T2 trigger sends new upcoming each change). Renderer triggers only on upcoming-set change, not position ticks (T2 Step 3).
- **Consistency:** reuses the decoupled best-effort cache-write pattern from the serve path; same `isCacheablePath`/`cacheKey`/`MediaCache`/`readCacheConfig`; `PREFETCH_DEPTH` matches between renderer slice and main cap.
- **Risks:** minor transient overlap with the engine's gapless preload of the immediate-next track (harmless, atomic rename); `pumpPrefetch` re-checks capacity after the `pathIfPresent` await to avoid over-spawning; cancel handles are idempotent (`finalize` guards). No core changes, no security-surface changes (prefetch uses the same endpoint/token path as serving, no new external input).
